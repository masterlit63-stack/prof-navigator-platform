# Часть A — Веб-версия (landing.html + quiz.html + result.html)

*Спецификация создана через Discovery Interview. Версия 1.1, 23 мая 2026.*

---

## A1. Обзор проекта

**Что создаём:** SPA-лендинг с встроенным квизом по профориентации и страницей результата.

**Целевая аудитория:**
- Подростки 9 класса (14–16 лет) — проходят сами
- Родители (35–50 лет) — проходят за ребёнка или вместе

**Главное действие:** пройти 10-вопросный квиз и получить именованный профессиональный профиль с рекомендациями.

**Технические ограничения:**
- Один HTML-файл — весь CSS и JS inline
- Никаких внешних библиотек, CDN, фреймворков
- Иконки — только inline SVG
- Шрифты — системный стек: `-apple-system, BlinkMacSystemFont, 'Segoe UI', system-ui, sans-serif`
- Работает без интернета после первой загрузки

## A2. Дизайн-система

```css
/* Цвета */
--bg:           #070e1b;   /* основной фон */
--card:         #0d1726;   /* фон карточек */
--accent:       #f97316;   /* оранжевый акцент */
--amber:        #fbbf24;   /* янтарь (градиент) */
--blue:         #0ea5e9;   /* голубой вспомогательный */
--green:        #10b981;   /* зелёный вспомогательный */
--text:         #f1f5f9;   /* основной текст */
--muted:        #94a3b8;   /* приглушённый текст */
--border:       rgba(255,255,255,0.07); /* граница */

/* Типографика */
--font: -apple-system, BlinkMacSystemFont, 'Segoe UI', system-ui, sans-serif;

/* Кнопки CTA */
background: linear-gradient(135deg, #f97316, #fbbf24);
box-shadow: 0 0 0 0 rgba(249,115,22,0.4); /* пульсирует анимацией pulse */
animation: pulse 2s infinite;

/* Карточки */
background: #0d1726;
backdrop-filter: blur(12px);
border: 1px solid rgba(255,255,255,0.07);
border-radius: 16px;

/* Брейкпоинты */
mobile:  320px–679px   (основной)
tablet:  680px+
desktop: 1024px+
```

**Правило:** оранжевый (`#f97316`) только на CTA-кнопках и важных акцентах. Не злоупотреблять — должен выделяться.

## A3. Архитектура файла

Один файл `index.html`. Внутри — три «экрана», переключаются через JavaScript (show/hide), без перезагрузки страницы.

```
index.html
├── <section id="screen-landing">   — лендинг
├── <section id="screen-quiz">      — квиз (10 вопросов)
└── <section id="screen-result">    — страница результата
```

Переключение:
```javascript
function showScreen(id) {
  document.querySelectorAll('[id^="screen-"]').forEach(s => s.style.display = 'none');
  document.getElementById(id).style.display = 'block';
  window.scrollTo(0, 0);
}
```

### Анимации на лендинге

| Элемент | Анимация | Реализация |
|---|---|---|
| H1, подзаголовок, кнопка | Появление при загрузке | CSS `@keyframes fadeInUp`, `animation-delay` |
| Блоки при скролле | Fade-in при попадании в viewport | `IntersectionObserver`, `opacity 0→1 + translateY` |

| CTA-кнопки | Пульсация glow | `@keyframes pulse` с `box-shadow` |
| FAQ аккордеон | Разворачивание | CSS `max-height: 0 → auto`, `transition: 0.3s ease` |

### [Экраны 1–10] Вопросы

**Элементы каждого вопроса:**
- Прогресс-бар сверху (нелинейный: вопрос 1=15%, 2=25%, 3=35%, 4=44%, 5=55%, 6=63%, 7=72%, 8=85%, 9=92%, 10=100%)
- Текст «Вопрос N из 10» (под баром)
- Заголовок вопроса (крупно)
- 4 карточки-ответа (вертикально на мобиле, 2×2 на планшете)
- Кнопка «← Назад» (мелкая)

**Критическое требование — «без скролла»:**
Весь экран вопроса (заголовок + 4 карточки) должен помещаться в viewport на экране 320px без прокрутки.
```css
.answer-card {
  min-height: 52px;
  max-height: 72px;
  padding: 12px 16px;
  font-size: 15px;
}
.question-title {
  font-size: 20px;
  line-height: 1.3;
  max-height: 3em;
}
```

**Варианты ответов — кардинальное различие:**
Каждый из 4 вариантов описывает принципиально разный тип деятельности.

❌ Плохо: «Анализировать данные» / «Изучать информацию» / «Работать с фактами»
✅ Хорошо: «Разбираться в задачах» / «Придумывать и создавать» / «Помогать людям» / «Строить руками»

**Механика выбора:**
```
t=0ms:    click на карточку
t=0ms:    addClass 'selected' (оранжевая подсветка + галочка)
t=50ms:   показать микрокопию (fadeIn 100ms)
t=50ms:   сохранить ответ в scores[profile]++
t=650ms:  начать slide-анимацию (translateX)
t=900ms:  новый вопрос полностью виден
```

**Анимация смены вопросов:** текущий уходит влево (`translateX(-100%)`), новый приходит справа. Transition: 250ms ease.

**Микрокопи-валидация** (появляется после выбора):
- Вопрос 1: `«Хороший старт!»`
- Вопрос 3: `«Запомним это про тебя»`
- Вопрос 5: `«Уже на полпути!»`
- Вопрос 8: `«Почти готово — финальный рывок»`
- Остальные: `«Записали»`

```

[Продолжить]  [Начать заново]
```

### Ничья в профилях

Если разница между топ-1 и топ-2 ≤ 1 очко → показать комбинированный профиль (см. A5).
Если комбинации нет → показать профиль с наибольшим счётом (fallback).

## A11. Что НЕ входит в v1

- Реальный AI / API — результаты через JS-шаблоны
- Email-рассылка — форма email только показывает toast
- Аналитика — Яндекс Метрика добавить перед запуском трафика
- 404.html — отдельной задачей
- Telegram-бот — этап 2

### Архитектурные запреты (нельзя нарушать)

| Запрет | Почему |
|---|---|
| ❌ Email-форма ДО результата | Убийца конверсии №1 — теряем 40–60% завершивших |
| ❌ Скролл внутри экрана с вопросом | На мобиле критично — пользователь думает «сломалось» |
| ❌ Кнопка «Далее» после выбора | Лишнее действие = точка выхода. Только автопереход |
| ❌ Похожие варианты ответов | Пользователь выбирает наугад → не доверяет результату |
| ❌ Результат короче 3 абзацев | «5 минут на пустышку» → негативные отзывы, нулевой шеринг |
| ❌ Больше 10 вопросов без прогресс-бара | Без видимого прогресса пользователь уходит на вопросе 5+ |

## B6. Технические требования

### Обязательные вызовы при старте

```javascript
Telegram.WebApp.ready()
Telegram.WebApp.expand()                         // на весь экран
Telegram.WebApp.ClosingConfirmation.enable()     // защита при квизе

const theme = Telegram.WebApp.themeParams        // цвета темы пользователя
const safeArea = Telegram.WebApp.safeAreaInset   // отступы для notch/панели
```

### Хранение данных

| Что | Где | Ключ |
|---|---|---|
| Выбранная роль | CloudStorage | `role` |
| Прогресс квиза | CloudStorage | `quiz_progress` |
| Результат | CloudStorage | `result` |
| Личный план | CloudStorage | `plan` |
| Кеш профессий | DeviceStorage | `professions_cache` |

### Дизайн-система (через themeParams)

```css
/* Базовые переменные от Telegram: */
--tg-bg: var(--tg-theme-bg-color);
--tg-text: var(--tg-theme-text-color);
--tg-button: var(--tg-theme-button-color);
--tg-hint: var(--tg-theme-hint-color);
--tg-secondary-bg: var(--tg-theme-secondary-bg-color);

/* Наши акценты поверх темы: */
--accent: #f97316;       /* оранжевый */
--accent-amber: #fbbf24; /* янтарь */
--success: #10b981;      /* зелёный — выполнено */
```

### Требования к тапу

- Все интерактивные элементы: **min-height: 44px**
- Карточки ответов в квизе: **min-height: 64px**
- Тап-зона чекбоксов: **44×44px**

### Производительность

- LCP ≤ **2.5 сек** · INP ≤ **200 мс**
- Нет внешних библиотек (кроме Telegram Web App SDK)
- Skeleton screens вместо спиннеров
- Все иконки — inline SVG

### Стек

| Задача | Решение |
|---|---|
| Хранение профиля | CloudStorage (Telegram) |
| AI-запросы | Edge Function (Vercel) — API-ключ скрыт |
| AI-модель | Gemini 2.5 Flash-Lite (~$0.00045/квиз) |
| Оплата | Telegram Stars |
| Аналитика | Яндекс Метрика (закон 152-ФЗ) |
| Авторизация | Telegram `initData` + HMAC-SHA256 |

## B8. Минимальный набор данных для запуска

**Профессии в базе v1:** 20 профессий (не 1500 как у CareerExplorer):
- Описание (3–4 предложения)
- Навыки (5–7 тегов)
- Зарплата РФ (вилка)
- Предметы ЕГЭ (2–3)
- Вузы (2–3 с ссылками)
- Оценка 0–10 по 6 осям (для radar chart)

**Примеры профессий:** биотехнолог, дата-аналитик, архитектор, психолог, учитель, ветеринар, программист, дизайнер, врач, журналист, юрист, инженер, повар-шеф, маркетолог, логопед, переводчик, режиссёр, строитель, агроном, социальный работник.

**Архетипов:** 6 штук:
- Исследователь (аналитика + технологии)
- Творец (творчество + коммуникации)
- Помощник (работа с людьми + организация)
- Мастер (природа/руки + аналитика)
- Организатор (организация + коммуникации)
- Первопроходец (творчество + аналитика)
