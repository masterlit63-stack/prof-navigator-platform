# ПрофНавигатор — Бриф разработки Telegram Mini App

**Составлен:** 30 мая 2026  
**Основа:** синтез исследований №1–5 (RESEARCH.md) + экспертные оценки UX/маркетинга/Telegram-разработки  
**Назначение:** пошаговый план разработки TMA для разработчика

---

## Контекст продукта

**Что делаем:** Telegram Mini App по профориентации для подростков 13–17 лет.  
**Почему TMA:** ни одного полноценного TMA по профориентации не существует — только текстовые боты без дизайна. Ниша пуста.  
**Наша формула:** TMA + бесплатный старт + 15 минут + российский контекст (ЕГЭ, вузы РФ) + конкретный план действий.

---

## Часть 1 — Список экранов MVP (первая версия)

| # | Экран | Зачем нужен |
|---|---|---|
| 1 | **Приветствие** | Первое впечатление, должен цеплять за 3 секунды |
| 2 | **Выбор роли** | Меняет тональность и контент всего пути |
| 3 | **Квиз (1–15)** | Ключевой сбор данных; без него нет результата |
| 4 | **«Считаем результат»** | Анимация-пауза повышает воспринимаемую ценность |
| 5 | **Результаты** | Ради этого экрана пришёл пользователь |
| 6 | **Карточка профессии** | Конкретика делает результат доверенным |
| 7 | **Личный план** | Главное отличие от всех конкурентов |
| 8 | **Повторный визит** | Персонализированная встреча вернувшегося пользователя |

### Экран 1 — Приветствие

**Что видит пользователь:**

```
┌─────────────────────────────────┐
│  [иллюстрация: дорога/горизонт] │
│                                 │
│  Привет, {имя из Telegram}! 👋  │
│                                 │
│  Узнай, какие профессии         │
│  подходят именно тебе —         │
│  за 15 минут, бесплатно         │
│                                 │
│  ● 15 вопросов                  │
│  ● Результат сразу              │
│  ● Без регистрации              │
│                                 │
│  [Уже 12 000 подростков         │
│   нашли свой путь]              │
│                                 │
│  ════════════════════════════   │
│  [      Начать →      ]         │  ← MainButton (Telegram)
└─────────────────────────────────┘
```

**Элементы:**
- Иллюстрация (SVG или статичное изображение, не фото)
- Имя пользователя из `Telegram.WebApp.initDataUnsafe.user.first_name`
- Заголовок-обещание (конкретное, не описание теста)
- 3 буллета: «15 вопросов», «Результат сразу», «Без регистрации»
- Счётчик социального доказательства
- `MainButton` Telegram с текстом «Начать»

**Действия:**
- Нажать «Начать» → переход на Экран 2 (выбор роли)

**Telegram API:**
```javascript
Telegram.WebApp.expand()                    // разворачиваем на весь экран
Telegram.WebApp.MainButton.setText('Начать')
Telegram.WebApp.MainButton.show()
Telegram.WebApp.ClosingConfirmation.enable() // включить сразу
```

**Что НЕ делаем:** не просим email, телефон, имя — Telegram уже авторизовал.

### Экран 3 — Квиз (один вопрос, повторяется 15 раз)

**Что видит пользователь:**

```
┌─────────────────────────────────┐
│  ← (BackButton)   Вопрос 5/15  │
│  ████████░░░░░░░░░░░░░░░░░░░░   │  ← прогресс-бар (нелинейный)
│                                 │
│  Тебе дали свободный день.      │
│  Чем займёшься?                 │
│                                 │
│  ┌───────────────────────────┐  │
│  │ 🔬 Разберу как работает   │  │
│  │    какая-нибудь вещь      │  │
│  └───────────────────────────┘  │
│                                 │
│  ┌───────────────────────────┐  │
│  │ 🎨 Сделаю что-то руками:  │  │
│  │    нарисую, сошью, сделаю │  │
│  └───────────────────────────┘  │
│                                 │
│  ┌───────────────────────────┐  │
│  │ 👥 Позову друзей, пойдём  │  │
│  │    куда-нибудь вместе     │  │
│  └───────────────────────────┘  │
│                                 │
│  ┌───────────────────────────┐  │
│  │ 📖 Почитаю / посмотрю     │  │
│  │    что-то интересное      │  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘
```

**Элементы:**
- `BackButton` Telegram (ведёт к предыдущему вопросу)
- Счётчик «Вопрос X/15» — справа вверху
- Прогресс-бар горизонтальный — **нелинейный**: вопрос 1=15%, 5=55%, 8=85%, 15=100%
- Текст вопроса — крупный, конкретный, жизненная ситуация (не абстрактный)
- 4 карточки-ответа (min-height: 64px каждая)
- Эмодзи + текст в каждой карточке

**Действия:**
- Нажать карточку → выделение (подсветка) → через 300 мс автопереход к следующему вопросу
- `BackButton` → возврат к предыдущему вопросу с уже выбранным ответом
- `HapticFeedback.impactOccurred('light')` на каждый нажатый ответ

**Сохранение прогресса:**
```javascript
// После каждого ответа:
Telegram.WebApp.CloudStorage.setItem('quiz_progress', JSON.stringify({
  current: questionIndex,
  answers: answersArray
}))
```

**Правила вопросов:**
- Конкретные жизненные ситуации, НЕ «оцените склонность к...»
- Все 4 варианта — равноценны (нет «правильного»)
- Нет слов «правильно/неправильно/лучший»
- Под вопросом маленькая подсказка: «Это поможет понять, как ты любишь работать»

**Что видит пользователь:**

```
┌─────────────────────────────────┐
│                                 │

│      вращающийся индикатор]     │

│                                 │
│                                 │
└─────────────────────────────────┘
```

**Элементы:**
- Анимация (CSS, без тяжёлых библиотек)
- 3 строки с прогрессом — появляются последовательно, каждые 800 мс
- Длительность экрана: **2.5–3 секунды** (даже если AI ответил быстрее — держать паузу)

**Действия:** нет — экран блокирует взаимодействие, пользователь ждёт.

**Что делаем в это время:**
- Отправляем ответы на сервер (Edge Function)
- Получаем результат от AI (Gemini Flash-Lite)
- Готовим данные для экрана результатов
- `MainButton` скрыт

**BackButton:** скрыт (`Telegram.WebApp.BackButton.hide()`)

## Часть 4 — Чего НЕ будет в первой версии

| Функция | Почему не в v1 | Когда добавить |
|---|---|---|
| AI-чат / советник | Требует бэкенда, диалоговой логики, промпт-инжиниринга | v2, после первых 500 пользователей |
| Список профессий с фильтрами | Нужна большая база; в v1 только топ-3 из результата | v2, через 1–2 месяца |
| Бейджи и уровни (геймификация) | Украшение — сначала работающий core | v2 |
| Шаринг в Stories (`shareToStory`) | Требует медиа-файла; API нестабильный | v2, когда обкатаем `shareMessage` |
| Режим «для родителя» (отдельный UI) | Отдельный UX-поток, отдельное тестирование | v2 |
| Dashboard для учителя | Полноценная B2B-функция | v3, после школьного пилота |
| Freemium-блокировка (paywall) | Сначала растим аудиторию, потом монетизируем | v2, через 1–2 месяца |
| Telegram Stars (оплата) | Требует юридического оформления | v2 |
| Стрики и push-уведомления | Нужен бот с расписанием отправки | v2 |
| Сравнение профессий (side-by-side) | Сложный UX | v3 |
| Скачивание PDF | Требует серверной генерации | v3 |
| Ветвление вопросов (branching) | Усложняет логику; в v1 линейный квиз | v2 |

## Часть 5 — Технические требования

### Обязательные вызовы Telegram API при старте

```javascript
// Первые строки при инициализации TMA:
Telegram.WebApp.ready()
Telegram.WebApp.expand()                         // на весь экран
Telegram.WebApp.ClosingConfirmation.enable()     // защита от случайного закрытия

// Цвета из темы пользователя (обязательно):
const theme = Telegram.WebApp.themeParams
// Использовать: theme.bg_color, theme.text_color, theme.button_color, theme.hint_color

// Безопасные отступы (для iPhone notch, Android панель):
```

### Хранение данных

| Что храним | Где | Ключ |
|---|---|---|
| Выбранная роль | CloudStorage | `role` |
| Прогресс квиза (ответы) | CloudStorage | `quiz_progress` |

| Личный план (шаги) | CloudStorage | `plan` |
| Список профессий (кеш) | DeviceStorage | `professions_cache` |

### Дизайн-система (адаптивная через themeParams)

TMA адаптируется к теме Telegram пользователя. Базовые токены:

```css
/* Читать из Telegram.WebApp.themeParams */
--tg-bg: var(--tg-theme-bg-color);
--tg-text: var(--tg-theme-text-color);
--tg-button: var(--tg-theme-button-color);
--tg-hint: var(--tg-theme-hint-color);
--tg-secondary-bg: var(--tg-theme-secondary-bg-color);

/* Наши акценты поверх темы: */
--accent: #f97316;       /* оранжевый — основной */
--accent-amber: #fbbf24; /* янтарь — вторичный */
--success: #10b981;      /* зелёный — выполнено */
```

### Требования к кнопкам и тапу

- Все интерактивные элементы: **min-height: 44px** (стандарт Apple HIG)
- Карточки ответов в квизе: **min-height: 64px**
- Отступы между карточками: **12px**
- Тап-зона вокруг чекбоксов: **44×44px minimum**

### Производительность

- LCP (Largest Contentful Paint) ≤ **2.5 сек**
- INP (Interaction to Next Paint) ≤ **200 мс**
- Нет внешних библиотек (кроме Telegram Web App SDK)
- Skeleton screens вместо спиннеров при любой загрузке
- Все иконки — inline SVG

### AI-запросы

- Обработка на сервере (Edge Function Vercel) — API-ключ не в браузере
- Модель: **Gemini 2.5 Flash-Lite** (~$0.00045 за один квиз)
- Запрос отправляется после 15-го вопроса (пока показываем Экран 4)
- Промпт включает: все 15 ответов + выбранная роль + язык = Russian

### Авторизация

- Пользователь авторизован через Telegram автоматически
- `initDataUnsafe.user` → имя, username, ID пользователя
- Проверка подлинности на сервере через `initData` + bot token (HMAC-SHA256)
- Никаких форм регистрации нет и не будет

## Часть 7 — Минимальный набор данных для запуска

**Профессии в базе v1:** достаточно **20 профессий** с полными данными (не 1500 как у CareerExplorer):
- Описание (3–4 предложения)
- Навыки (5–7 тегов)
- Зарплата РФ (вилка)
- Предметы ЕГЭ (2–3)
- Вузы (2–3 с ссылками)
- Соответствие осям (оценка 0–10 по 6 осям для radar chart)

**Примеры профессий для v1:** биотехнолог, дата-аналитик, архитектор, психолог, учитель, ветеринар, программист, дизайнер, врач, журналист, юрист, инженер, повар-шеф, маркетолог, логопед, переводчик, режиссёр, строитель, агроном, социальный работник.

**Архетипов:** 6 штук (покрывают все комбинации):
- Исследователь (аналитика + технологии)
- Творец (творчество + коммуникации)
- Помощник (работа с людьми + организация)
- Мастер (природа/руки + аналитика)
- Организатор (организация + коммуникации)
- Первопроходец (творчество + аналитика)
