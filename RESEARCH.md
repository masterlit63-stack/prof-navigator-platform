## 2.1 ОБЯЗАТЕЛЬНЫЕ ЭКРАНЫ (по приоритету)

### Экраны первого запуска (Retention Hook)
- **Сплэш / приветствие** — имя пользователя из Telegram сразу (без регистрации), краткое value proposition «за 5 минут узнай, какие профессии тебе подходят»
- **Онбординг** (2–3 экрана max) — Duolingo-подход: скрытый онбординг через вопросы, «7 вопросов до старта», прогресс-бар виден сразу
- **Выбор роли** — подросток / родитель / учитель (влияет на персонализацию и тональность)
- **Цель прохождения** — «хочу понять свои интересы», «выбираю вуз», «ищу профессию для ребёнка» и т.д.

### Основные функциональные экраны
- **Квиз / тест** — карточки по одному вопросу на экран, прогресс-бар, 15–20 вопросов (не больше), смешанные форматы (выбор, шкала, свайп), анимация перехода между вопросами
- **Результаты / профиль** — radar/spider chart навыков, топ-3 типа личности (архетип), процент совпадения с профессиями, краткое описание «ты такой человек, который...»
- **Список профессий** — карточки с фото-иллюстрацией, зарплатная вилка, краткое описание, кнопка «подробнее», фильтры по интересам/отраслям
- **Карточка профессии** — детальная: чем занимается, навыки, вузы, зарплата, «похожие профессии», CTA «добавить в план»
- **Личный план развития** — roadmap-визуализация: горизонтальная шкала времени или вертикальный список шагов с чекбоксами, категории (учёба, кружки, проекты, книги)

### Дополнительные экраны (могут быть позже)
- **AI-чат / AI-советник** — чат-интерфейс для вопросов («а что если я хочу быть дизайнером, но боюсь?»)
- **Профиль / достижения** — уровень, бейджи, история прохождений
- **Сравнение профессий** — side-by-side карточки, 2–3 профессии
- **Для родителей** — отдельный view результатов ребёнка с рекомендациями «как поддержать»
- **Для учителей** — агрегированный dashboard класса (B2B)
- **Шаринг результата** — красивая карточка для отправки в чат Telegram

## 2.2 UI-КОМПОНЕНТЫ

### Критически важные
- **Прогресс-бар квиза** — горизонтальный, показывает «вопрос 5 из 18», goal gradient effect: чем ближе к концу, тем выше вовлечённость. Duolingo: делит на главы по 5 вопросов
- **Карточки профессий** — обложка (иллюстрация/иконка), название, короткий дескриптор, процент совпадения, 2–3 тега. Свайп-паттерн (Tinder-механика для открытия новых профессий) — интуитивен для подростков
- **Radar/Spider chart** — визуализация 5–6 ключевых характеристик (аналитика, коммуникации, творчество, технологии, работа с людьми, природа). Данные из квиза. Uxcel.com и UX Skill Mapper — хорошие референсы
- **Один вопрос на экран** — снижает когнитивную нагрузку, mobile-first, каждый экран = одно решение
- **Bottom Navigation** (в TMA — не рекомендуется дублировать нативный Back Button; использовать Telegram MainButton для primary CTA)

### Геймификация-компоненты
- **Streak-система** — ежедневные заходы, flame-иконка, push через бота. Duolingo: 7-дневный стрик увеличивает retention в 3.6x
- **XP / очки** — начисляются за прохождение квиза, изучение профессий, добавление шагов в план
- **Бейджи / достижения** — «Первый тест», «Исследователь» (5 профессий), «Планировщик» (первый шаг в плане)
- **Уровни** — Новичок → Исследователь → Навигатор → Профессионал
- **Лидерборд** (опционально для школ) — среди учеников класса/школы

### Вспомогательные
- **Skeleton screens** — пока грузятся данные, показываем контуры карточек
- **Micro-interactions** — анимация при правильном ответе, конфетти при завершении квиза
- **Sticky CTA** — Telegram MainButton всегда внизу («Следующий вопрос», «Смотреть результаты»)
- **Модальные окна** — нативные Telegram popup (не кастомные) для подтверждений и алертов
- **Пустые состояния** — если профессий в плане нет, показываем иллюстрацию и CTA «начать тест»

## 2.3 UX-ПАТТЕРНЫ ДЛЯ ПОДРОСТКОВ

### Вовлечённость
- **Конверсия чат-интерфейса vs форм:** 69.9% пользователей предпочитают чат-формат. Chatbot vs form: выше NPS (24 vs 13), воспринимается как интерактивный и интуитивный. Для подростков особенно важно: текстово-перегруженный контент = отпугивает. Вывод: квиз лучше делать в формате «один вопрос — одна карточка» как разговор, а не длинная форма
- **Gamification работает:** Duolingo streaks +60% commitment, XP leaderboards +40% engagement, badges +30% completion
- **Короткий онбординг побеждает:** Duolingo скрывает онбординг в первом задании — пользователь уже «внутри продукта» до регистрации. Применимо к ПрофНавигатор: первые 3 вопроса квиза = онбординг, результаты показываем до требования аккаунта
- **Mascot / персонаж** — Duo у Duolingo, SkillCity у ASI. Снижает тревогу, делает интерфейс дружелюбным. Для подростков — важно
- **Физические/осязаемые награды** работают лучше цифровых (SkillCity: реальные призы за XP). Применимо: скидки у партнёров, сертификаты для портфолио

### Удержание (Retention)
- **Progressive disclosure** — не показывать всё сразу. Сначала результаты, потом план, потом детали профессий
- **Return hooks** — бот напоминает: «Ты не посмотрел профессию Архитектор, которую мы для тебя нашли»
- **Social sharing** — карточка результата для отправки в чат. Telegram's native shareToStory() или shareMessage()
- **Сохранение прогресса** — Cloud Storage TMA (до 1024 ключей) для промежуточных результатов квиза

### Тональность для подростков 13–17
- Разговорный язык, «ты» (уже в правилах проекта)
- Короткие предложения
- Избегать слова «правильный/неправильный» — все ответы в квизе равноценны
- Показывать «почему»: «Этот вопрос поможет понять, любишь ли ты работать с людьми»
- Не требовать регистрацию в начале — откладывать как можно дольше

## 2.4 СПЕЦИФИКА TELEGRAM MINI APPS

### Доступные API (официальная документация Telegram, 2026)

**Навигация:**
- `MainButton` / `BottomButton` — кнопка внизу экрана, основной CTA. Использовать для «Далее», «Смотреть результаты», «Начать квиз»
- `BackButton` — нативная кнопка назад в хедере. НЕ дублировать свою кнопку назад
- `close()` — закрыть TMA (использовать с ClosingConfirmation если пользователь в середине квиза)
- `expand()` — развернуть на весь экран (вызывать сразу при старте)

**Хранение данных:**
- `CloudStorage` — server-side, до 1024 items/user. Хранить результаты квиза, прогресс плана, настройки
- `DeviceStorage` — local, 5 MB. Кеш карточек профессий
- `SecureStorage` — зашифрованное хранилище (Keychain/Keystore). Для чувствительных данных

**Обратная связь:**
- `HapticFeedback.impactOccurred()` — нажатие кнопки, свайп карточки
- `HapticFeedback.notificationOccurred('success')` — завершение квиза, достижение
- `HapticFeedback.selectionChanged()` — переключение между вариантами ответа

**Тема и адаптация:**
- `themeParams` — автоматическая адаптация к тёмной/светлой теме Telegram пользователя (ОБЯЗАТЕЛЬНО)
- `safeAreaInset` и `contentSafeAreaInset` — учитывать для iOS notch и нижней панели
- `viewportHeight` / `viewportStableHeight` — использовать stable для layout, чтобы не прыгало при появлении клавиатуры

**Социальные функции:**
- `shareMessage()` — поделиться результатом в чат (через бота)
- `shareToStory()` — опубликовать результат в Stories
- `requestContact()` — запросить телефон (для родительского аккаунта)

**Подтверждения:**
- `showPopup()`, `showAlert()`, `showConfirm()` — нативные диалоги Telegram (не кастомные overlay)
- `ClosingConfirmation` — включать во время прохождения квиза, отключать после завершения

### Best Practices навигации в TMA
1. Один экран — одно действие (single-screen focus)
2. Value-first: показывать пользу ДО запроса любых данных или разрешений
3. Lazy permission: просить разрешения только в момент, когда они нужны (Just-in-time)
4. Skeleton screens вместо спиннеров — воспринимаются лучше
5. Offline state — показывать «Нет соединения» вместо пустого экрана
6. Performance: LCP ≤ 2.5s, INP ≤ 200ms. Минимальный JS/CSS

### Конкретные EdTech TMA-примеры
- **Code Learn** (@code_learn_v3_bot) — технические вопросы, выбор темы, ответ в чате, мгновенная проверка
- **Crazy Llama English** (@crazyllamaenglish_bot) — ежедневные квизы, AI-подсказки, стрики, маскот (лама), геймификация
- **Madlen** — AI-платформа для учителей, 50 000+ учеников (Турция)

### Ограничения TMA
- Нет iOS горизонтальных свайпов от края — конфликт с закрытием TMA. Использовать кнопки или вертикальный свайп
- Нет нативного drag-and-drop (сложно без кастомной реализации)
- Тема должна синхронизироваться с Telegram — нельзя жёстко задавать только тёмный фон без учёта themeParams
- Нельзя открывать внешние ссылки без `openLink()` — иначе TMA закроется

## 2.5 ДОВЕРИЕ И КОНВЕРСИЯ В EDTECH

### Социальное доказательство
- Количество прошедших («Уже 12 000 подростков нашли свой путь»)
- Отзывы + фото (или аватарки) реальных пользователей
- Упоминание школ/партнёров («Используется в 15 школах Самары»)
- Логотипы партнёрских вузов и работодателей

### Прозрачность AI
- «Как это работает» — краткое объяснение алгоритма на странице результатов: «Мы сравнили твои ответы с профилями 50 000 специалистов»
- Никакого «чёрного ящика» — объяснять, почему конкретная профессия подходит
- «AI — это инструмент, а не приговор» — добавлять фразы, что результат можно пересмотреть
- Показывать confidence: «87% совпадение» + пояснение что это значит

### Privacy (особенно для детей 13–17)
- COPPA: дети до 13 — только с родительского согласия. В России: аналог — согласие законного представителя
- GDPR-K: до 16 лет — родительское согласие для обработки данных
- В Telegram Mini App — пользователь уже авторизован через Telegram; данные не надо собирать отдельно
- UX-паттерн: на экране «что мы собираем» — простой язык, иконки замка, список: имя, возраст, ответы квиза — ничего лишнего
- «Данные не продаём» — явно и крупно
- Возможность удалить данные — через команду боту

### Конверсия в оплату (для платных функций)
- Показывать premium-результат размытым (blur) с кнопкой «Разблокировать»
- Freemium: базовый результат бесплатно → детальный отчёт / план / AI-чат платно
- Telegram Stars — нативный способ оплаты внутри TMA (без внешних платёжных систем)
- Родительская оплата: отправить ссылку на оплату родителям через бота

## 1. КОНКУРЕНТЫ

### 1.1 CareerExplorer (careerexplorer.com)

**Формат:** ~100 вопросов, 30–40 минут, шкала Ликерта + сценарные вопросы

**Что получает пользователь:**
- Бесплатно: список из 1500+ карьер с совпадениями, архетип личности (Visionary, Scholar, Builder), базовый отчёт

**Хорошо:**
- Полностью бесплатный, без пейволла
- Огромная база карьер
- Геймификация (бейджи, прогресс-бар)
- Можно вернуться и изменить ответы

**Плохо:**
- Слишком длинный (30–40 мин) — подростки не дойдут до конца
- Запрашивает этничность и доход семьи — чужеродно для РФ
- Слабые инсайты несмотря на объём
- Технические баги

---

### 1.2 Truity Career Aptitude Test (truity.com)

**Формат:** 94 вопроса, 10–15 минут, трёхточечная шкала (Dislike / Neutral / Like) на конкретные виды деятельности. Основан на Holland Code + Big Five.

**Что получает пользователь:**
- Бесплатно: краткое резюме типа личности и базовые карьерные рекомендации
- Платно ($29): 36-страничный PDF, 46 персональных карьер с зарплатами и перспективами

**Хорошо:**
- Быстрый и удобный (15 мин)
- Научная база (Holland + Big Five)
- 4.8/5 на 2584 отзывах
- Без регистрации при старте

**Плохо:**
- Бесплатная часть очень скудная — реальная ценность за пейволлом
- Нет конкретных следующих шагов
- Ориентирован на взрослых, не адаптирован для школьников
- Нет поддержки

---

### 1.3 16Personalities (16personalities.com)

**Формат:** ~60–93 вопроса, 10–15 минут, шкала согласия на утверждения о поведении. Измеряет MBTI-подобные шкалы.

**Что получает пользователь:**
- Бесплатно: один из 16 типов личности с именем, аватаром, развёрнутым описанием, сильными/слабыми сторонами
- Базовая связь с карьерой
- Платно: расширенный карьерный анализ (Career Suite)

**Хорошо:**
- Самый узнаваемый тест в мире, культурный феномен среди подростков
- Вирусный: каждый тип имеет имя и аватар — люди охотно делятся
- Полностью бесплатный базовый тест
- Понятен без психологического образования

**Плохо:**
- Профориентация — не основная функция, карьерные рекомендации поверхностны
- MBTI критикуется за научную несостоятельность
- Нет конкретных следующих шагов
- Нет российского контекста (вузы, ЕГЭ)

### 1.4 Профориентатор МГУ (proforientator.ru)

**Формат:** 157 вопросов, 60+ минут. Разработан специалистами МГУ, психометрически обоснован.

**Что получает пользователь:**
- Платно (6 900 руб.): список профнаправлений + консультация психолога 45 минут, рекомендации по ЕГЭ/ОГЭ, подбор вузов
- Расширенный пакет с кандидатом наук — 9 400 руб.

**Хорошо:**
- Самая серьёзная научная база среди российских продуктов
- Живая консультация психолога
- Конкретный результат: профессии + вузы + ЕГЭ
- Льготы для многодетных и детей с ОВЗ

**Плохо:**
- Полностью платный (6 900 руб.) — высокий барьер входа
- 157 вопросов / 60 минут — недопустимо долго для подростка
- Морально устаревший UX (интерфейс 2010-х)
- Модель не масштабируется: завязана на живом психологе

## 3. UX И СЦЕНАРИИ

### Сценарий А: Подросток проходит сам (14–17 лет)

**Точка входа:** TikTok/Reels с подписью «Узнай, кем ты будешь» или ссылка от друга.

**Поведение:**
- Читает первый экран 3–4 секунды. Не зацепило — закрывает.
- Листает вопросы быстро: 5–8 секунд, выбирает «на ощущение»
- Активно использует «назад» если пожалел об ответе
- Ожидает прогресс-бар — без него тревога «это вообще когда-нибудь кончится?»
- После последнего вопроса ждёт мгновенного результата. Задержка 2 сек = баг
- Если результат понравился — делает скриншот или шерит в сторис

**Критический момент:** вопросы 6–8. Здесь самый высокий dropout — подросток «устаёт» от абстрактных формулировок и бросает.

---

### Сценарий Б: Родитель проходит вместе с ребёнком

**Точка входа:** статья «Как помочь ребёнку выбрать профессию».

**Поведение:**
- Читает стартовый экран внимательно — проверяет «насколько это серьёзно»
- Передаёт управление ребёнку, но сидит рядом. Квиз превращается в разговор.
- Ищет кнопку «вернуться и изменить» — хочет убедиться в правильности ответа
- На странице результата: родитель читает всё, ребёнок смотрит на картинку и заголовок
- Ищет «что делать дальше» — конкретные шаги, ссылки. Если нет — разочарование.

**Критический момент:** расплывчатый результат («ты творческий человек») = «нас обманули». Нужна конкретика: профессии, учебные заведения, навыки.

---

### Сценарий В: Пользователь бросает квиз на середине

**Где и почему бросают:**

1. **На 3–4 вопросе** — вопросы слишком похожи или кажутся «школьными»
2. **На вопросе с email** — если форму вставляют ДО результата. Конверсия падает на 40–60%
3. **Без прогресс-бара** — на 7-м вопросе думает, что будет 20, и закрывает
4. **Непонятный вопрос** — «интроверт», «аналитика» — стоп-сигналы для подростка. Не хочет признаться что не понял — уходит
5. **Зависание/перезагрузка** — мобильный пользователь думает «сломалось» и закрывает

---

### Топ-5 практик которые работают

**1. Одна карточка — один вопрос без скролла**
Весь вопрос + все варианты на экране без прокрутки. На мобиле критично.

**2. Прогресс-бар с реальными числами**
«Вопрос 5 из 12», не просто полоска. Sunk cost effect: «я уже столько прошёл, не брошу». Повышает completion rate на 20–30% (данные Interact и Outgrow).

**3. Ответы-карточки вместо радиокнопок**
Большие кликабельные карточки снижают когнитивную нагрузку. Клик = выделение = автопереход к следующему вопросу. Никаких кнопок «Далее».

**4. Auto-advance после выбора**
Автоматический переход после клика — квиз «живой», ощущение диалога, не заполнения анкеты.

**5. Анимация «Мы считаем результат»**
Экран-заглушка 2–3 секунды перед результатом резко повышает воспринимаемую ценность. «Раз считается долго — значит, серьёзно». Используют BuzzFeed, 16Personalities, Typeform.

**6. Conditional logic — ветвление вопросов**
Квизы с адаптивной логикой показывают **+64% completion rate** по сравнению с линейными (Interact, 2026).

**7. Социальное доказательство в процессе квиза**
Внутри квиза под вариантами: «67% выбрали это», на экране результата: «Аналитик получают только 22% участников».

**8. Preview результата до первого вопроса**
Показать мокап страницы результата на вводном экране. Interact: **+15–20% start rate**.

---

### Топ-5 ошибок которые бесят пользователей

**1. Email перед результатом** — убийца конверсии №1.
**2. Больше 15 вопросов без очевидной причины** — оптимум 10–15.
**3. Размытые похожие варианты ответов** — пользователь выбирает наугад.
**4. Абстрактные вопросы** — «оцените склонность к системному мышлению» непонятно.
**5. Результат — одно слово + три строчки** — пользователь потратил время на пустышку.
**6. Линейный равномерный прогресс-бар** — снижает completion. Нелинейный (1=15%, 5=55%, 8=85%) психологически комфортнее.
**7. Нет кнопки «Назад»** — ошибочный выбор без исправления = закрытая вкладка.
**8. Нет экрана для повторного визита** — localStorage → «Твой профиль: Аналитик. Посмотреть или пройти заново?»

---

### Как устроена страница результата (лучшие практики)

```
[1] Момент раскрытия — Большой заголовок-архетип: «Ты — Исследователь»
[2] «Это ты» — 3–5 коротких характеристик для узнавания
[3] Подходящие профессии — 3–6 карточек с объяснением
[4] Сильные стороны — 3–4 конкретных навыка
[5] Следующий шаг (CTA) + Email-форма
[6] Шеринг — Telegram, VK, скопировать ссылку
```

## 2.3 Прогноз рынка профориентации

### Рост рынка

- Рынок AI Career Coach: **$4,2 млрд в 2024 → $23,5 млрд к 2034** (CAGR 18,7%)
- Рынок онлайн-профориентации РФ: 1,41 млрд (2020) → 2,44 млрд (2024), +18%/год
- Запросы «профориентация» в Яндексе: 171 тыс. (2018) → 600 тыс. (2023) — рост **в 3,5 раза**
- Рынок переквалификации взрослых РФ: **52,5 млрд руб.** (2025)

### Ключевые тренды 2025–2026

- **AI-персонализация** становится ожидаемой нормой, не преимуществом
- **Геймификация** даёт +20–30% вовлечение; рынок геймификации $30,7 млрд → $46,4 млрд к 2027
- **Telegram Mini Apps**: 500 млн пользователей/мес, CAC ниже на 90–95% vs App Store
- **Профпробы и симуляции** заменяют абстрактные тесты
- **Взрослый сегмент** (25–40, смена профессии) растёт быстрее подросткового
- **B2B** (школы, HR) становится главным источником выручки

### Рост потребности в России

- Дефицит кадров: 1,5–2 млн специалистов сейчас, к 2030 — 3,1 млн
- 86% россиян считают профориентацию в школах нужной — но запрос не закрыт
- Только 2% выбирают профессию по результатам тестов; 40% — по личным интересам, 20% — по совету родителей
- Гос. программа «Билет в будущее» охватывает 1,3 млн школьников/год — создаёт привычку, но не даёт глубины
- Резюме подростков 14–18 лет выросли на **74%** за год (hh.ru, 2025) — мотивация есть, навигации нет

### Прогноз на 2026–2028

1. Профориентация станет **непрерывным процессом**, не разовым тестом в 9 классе
2. AI-персонализация — стандарт; без AI продукт будет восприниматься устаревшим
3. Взрослая аудитория **обгонит школьную** по обороту
4. Telegram — основной канал дистрибуции в РФ/СНГ
5. B2B (школы + предприятия) — главный источник выручки для качественных платформ
6. Государство будет **закупать лицензии** у лучших частных продуктов

## 1. Профилум (profilum.ru) — B2B лидер в российских школах

**Платформа:** Web, интеграция в ФГИС (Федеральная государственная информационная система)  
**Аудитория:** Школьники 6–11 класс через школы и региональные органы власти

**Функции:**
- Психометрический тест 207 вопросов, одобрен РАО + партнёрство с МГУ
- Параллельный тест ребёнок + родитель: наглядно показывает расхождение ожиданий
- Каталог 500+ профессий с региональными работодателями
- 17-занятийный образовательный курс об отраслях
- Встроен в проект «Билет в будущее» (Минпросвещения)
- Аналитика для регионов, 9 регионов-партнёров, 3 млн+ прошли

**Сильные стороны:**
- Государственная аккредитация — авторитетность для родителей и школ
- Уникальная механика «ребёнок + родитель» в одном отчёте — нет ни у кого
- Реальный доступ в школы через государственные контракты
- Региональный контекст: конкретные работодатели региона
- Анализ рынка труда на основе 50 млн вакансий и резюме

**Слабые стороны:**
- Недоступен частному пользователю — только через школу или B2B
- 207 вопросов — критически много, подросток бросит
- Цены не раскрываются (только через демо)
- Отзывы: задержки, технические проблемы, «выплата зарплат задержана» (внутренние проблемы)
- Закрытая платформа — нет публичного UX для оценки

**Незакрытое Профилумом:** прямой доступ без школы, быстрый формат, современный мобильный UX.

**Сильные стороны:**

**Слабые стороны (из реальных отзывов):**

## 3. CareerExplorer / Sokanu (careerexplorer.com) — самый популярный бесплатный глобальный тест

**Платформа:** Web  
**Аудитория:** Старшеклассники, студенты, профессионалы (США, глобально, на английском)

**Функции:**
- Адаптивный тест 150+ черт, реально занимает 60–90 мин
- 4 блока оценки: интересы, личность, ценности, история
- База 1 500+ карьер с % совместимости, зарплатами, требованиями (O*NET)
- Архетип личности (16 вариантов)
- Алгоритм обучен на 500+ млн ответов пользователей
- Полностью бесплатный
- Профиль карьеры, список степеней, Discord-сообщество

**Сильные стороны:**
- Полностью бесплатный, без пейволла
- Огромная и актуальная база (UX Designer, Data Scientist и т.д.)
- Не продаёт персональные данные
- Геймификация: бейджи, прогресс-бар, трекинг
- Постоянное обновление алгоритма

**Слабые стороны:**
- Обещает 30 мин — реально 60–90 мин; высокий dropout
- 1 500+ карьер в результате = перегрузка, нет чёткого «что делать дальше»
- Хобби «готовлю дома» → рекомендация в общепите (релевантность низкая)
- Запрашивает этничность и доход семьи — неприемлемо для РФ
- Технические баги в интерфейсе
- Нет российского контекста: ни ЕГЭ, ни вузов, ни рынка труда РФ
- Отчёт поверхностный несмотря на длину теста (критика ScholarshipInstitute)
- «PhD career psychologists» — маркетинговый термин, которого не существует

**Незакрытое:** российский контекст, конкретный план, краткость, нормальная релевантность результатов.

## 4. YouScience BrightPath (youscience.com) — аптитюдный тест через brain games

**Платформа:** Web (B2B — школы и дистрикты США)  
**Аудитория:** Школьники 5–12 класс в американских школах; 11 600+ школ

**Функции:**
- 9 «brain games» (мини-задачи с таймером) — измеряет реальные когнитивные способности
- 11 упражнений суммарно, 90 минут
- Аптитюды: идеегенерация, числовое мышление, пространственная визуализация, последовательное мышление, индуктивное мышление, скорость визуального сравнения, временная ориентация, словарный запас, рабочий подход
- Подбор карьер из базы 500+ профессий (O*NET), опросник интересов
- Экосистема: аптитюды → 200+ сертификаций → связь с работодателями
- Доступ к отчёту сохраняется 10 лет

**Цены:** B2B (школы, цены не раскрываются); физлица — $49 разово

**Сильные стороны:**
- Измеряет реальные способности (brain games), а не самовосприятие — объективнее
- Научная основа: Ball Aptitude Battery, 50+ лет исследований
- Показывает способности, о которых ребёнок не догадывался
- Экосистема оценка → сертификаты → работодатели — уникально
- Сложно «подогнать» ответы под желаемый результат

## Обязательные UI-элементы

### Критически важные (без них плохой UX)
- **Прогресс-бар квиза** — «Вопрос 5 из 15», нелинейный (goal gradient effect): completion +20–30%
- **Карточки-ответы вместо радиокнопок** — большие, кликабельные, автопереход после выбора
- **Radar/Spider chart** — 5–6 осей (аналитика, коммуникации, творчество, технологии, работа с людьми, природа)
- **Telegram MainButton** — единственный CTA внизу; не дублировать нативный BackButton
- **Skeleton screens** — вместо спиннеров при загрузке (воспринимается на 30% лучше)

### Важные для качества
- **Micro-interactions** — haptic feedback при ответе (`HapticFeedback.impactOccurred()`), конфетти при завершении квиза
- **Пустые состояния** — если план пустой, иллюстрация + CTA «пройди квиз»
- **Нативные диалоги Telegram** — `showPopup()`, `showConfirm()` вместо кастомных overlay
- **ClosingConfirmation** — включать во время квиза, отключать после завершения
- **themeParams** — адаптация к тёмной/светлой теме пользователя (обязательно в TMA)

### Для доверия и конверсии
- **Социальное доказательство** — «12 000 подростков уже нашли свой путь»
- **AI-прозрачность** — объяснять почему конкретная профессия: «Ты ответил, что любишь работать руками → поэтому предлагаем...»
- **Privacy UX** — простой список что собираем, иконка замка, «данные не продаём»
- **Freemium-конверсия** — базовый результат бесплатно; детальный план и AI-чат размыты с кнопкой «Разблокировать»
- **Telegram Stars** — нативная оплата внутри TMA

## Точка зрения 1 — UX-дизайнер

### Ошибки, которые делают новички в похожих продуктах

**1. Длинный тест = мёртвый продукт**
Профориентатор МГУ — 157 вопросов/60 мин. CareerExplorer обещает 30 мин, даёт 90 мин. Подросток закрывает на 6–8 вопросе. Данные: критическая точка отвала — вопросы 6–8. Правило для ПрофНавигатора: **максимум 15 вопросов**, каждый занимает 5–8 секунд.

**2. Email-гейт перед результатом**
Это убийца конверсии №1 в квизах. Пользователь вложил время → хочет результат → видит форму → закрывает. В Telegram Mini App эта ошибка невозможна в чистом виде (авторизация уже есть), но её аналог — требование чего-либо ДО показа результата (номер телефона, имя, класс). Результат — сначала, данные — потом.

**3. Абстрактные вопросы**
«Оцените склонность к системному мышлению» — подросток не знает что это и не хочет признаваться. Уходит молча. Вопросы должны быть конкретными жизненными ситуациями: «Тебе дали свободный день. Что выберешь?» — и карточки с вариантами.

**4. Размытый результат**
«Ты творческий человек с аналитическим складом ума» — это ни о чём. Реальные отзывы на ПроФориентатор: «тексты Барнума» — подходит всем и никому. Результат должен быть конкретным: архетип с именем + топ-3 профессии + одна конкретная задача на эту неделю.

**5. Нет кнопки «Назад»**
Подросток ответил «на ощущение» → пожалел → нет возврата → закрыл. Обязательно: в квизе Back Button Telegram работает как «вернуться к вопросу».

**6. Линейный прогресс-бар**
Равномерный прогресс психологически хуже нелинейного. Нелинейный: вопрос 1 = 15% заполнено, вопрос 5 = 55%, вопрос 8 = 85%. Создаёт ощущение «уже почти», снижает dropout на 20%.

**7. Нет экрана повторного визита**
Пользователь вернулся через 3 дня → видит пустой экран приветствия. Правильно: «Привет, Миша! Твой профиль готов. Продолжим?» + кнопки «Мои профессии» и «Пройти заново».

### Что обязательно должно быть

- **Один вопрос — один экран**, без скролла, весь контент виден сразу
- **Карточки-ответы** (не радиокнопки), автопереход после клика — квиз «живой», ощущение разговора
- **Анимация «Считаем результат»** — 2–3 сек перед результатом. Исследование: визуально воспринимается как более умный и точный алгоритм
- **Radar chart** на экране результата — визуализирует личность, не просто список слов. 5–6 осей: аналитика, коммуникации, творчество, технологии, работа с людьми, природа
- **Архетип с именем** — «Ты — Исследователь», не «у тебя высокие показатели по оси аналитика»
- **Личный план с чекбоксами** — конкретные шаги: курс, книга, кружок, проект. Можно отмечать выполненное — создаёт возвращаемость

### Что бесит пользователей (данные из отзывов и исследований)

| Раздражитель | Откуда известно | Решение |
|---|---|---|
| «Это вечно?» (нет прогресса) | Наблюдения, Interact | Прогресс-бар с числами |
| Похожие варианты ответа, непонятно что выбрать | UX-практика | Конкретные, контрастные варианты |
| Результат — одна строка | Отзывы на otzovik.com | Полноценный экран с описанием |
| Ничего не происходит после результата | Все конкуренты | Конкретный следующий шаг |
| Приложение закрылось, прогресс потерян | Telegram UX | CloudStorage, ClosingConfirmation |
| «Это про меня?» — не узнал себя | Отзывы CareerExplorer | Точные, образные характеристики |

## Точка зрения 2 — Маркетолог

### Что заставит прийти впервые

**Curiosity gap в заголовке** — не «тест на профориентацию», а «Узнай, кем ты мог бы стать» или «Большинство подростков выбирают не свою профессию». CTR выше на 30–50% (BuzzFeed, 16Personalities).

**Preview результата до старта** — показать мокап страницы результата: radar chart, имя архетипа. Пользователь видит что получит → +15–20% к началу прохождения (данные Interact).

**Распространение через школьный чат** — главный канал у подростков. Механика: пользователь получил результат → поделился в группе → друг пришёл. Нужна красивая карточка-результат для шаринга в Telegram Stories и чаты.

**«Твои друзья уже прошли»** — социальное доказательство в процессе квиза под вариантами ответа: «67% выбрали это». На экране результата: «Исследователем оказываются только 18% подростков» — делает результат редким и ценным.

### Что заставит остаться

**Стрик-система** — «Ты заходишь 7 дней подряд». Данные Duolingo: 7-дневный стрик увеличивает долгосрочный retention в 3.6 раза. Бот отправляет напоминание если стрик под угрозой.

**Повторные поводы зайти** — бот сам возвращается:
- «Мы нашли для тебя новую профессию — Технолог пищевого производства. Хочешь посмотреть?»
- «Ты добавил шаг в план 2 недели назад. Как продвигается?»
- «Новые вузы открыли набор по твоему направлению»

**Прогресс профиля** — уровни (Новичок → Исследователь → Навигатор → Профессионал) и бейджи. Незавершённый профиль = триггер зайти и завершить.

**Родительский крюк** — подросток показывает результат родителю. Родитель видит «рекомендации для родителей» → регистрируется → приводит ещё одного ребёнка. Цикл.

### Элементы, повышающие конверсию в оплату

**Freemium-блокировка** — базовый результат (архетип + топ-3 профессии) бесплатно и сразу. Детальный план развития, AI-чат и расширенный отчёт — размыты, кнопка «Разблокировать». Пользователь видит что теряет → конвертируется.

**Telegram Stars** — нативная оплата внутри TMA, без внешних шлюзов. Минимальное трение. Можно продавать: месячная подписка, разовый расширенный отчёт, консультация с живым специалистом.

**Родительский формат оплаты** — подросток прошёл тест → кнопка «Отправить результаты родителям» → родитель получает сообщение с результатами и кнопкой «Открыть полный план» → оплачивает. Взрослые платят охотнее.

**Социальное доказательство на экране оплаты** — не «купить за 299 руб.», а «Уже 3 200 подростков получили свой план развития. Готов?».

### Самые частые маркетинговые провалы конкурентов — что не повторять

| Провал | Кто так делает | Как мы делаем |
|---|---|---|
| Нет бесплатного входа | YouCan (85 BYN с первого шага) | Результат бесплатно, монетизация — в глубине |
| Скрытая реклама курсов в отчёте | ПроФориентатор | Честный независимый результат |
| Нет шаринга результата | Все Telegram-боты | Красивая карточка для Stories и чатов |
| Одноразовый продукт | Все конкуренты | Стрики, бот возвращается сам |
| 203 подписчика при хорошем продукте | КарьерХаб | Virality-механики с первого дня |

## Точка зрения 3 — Telegram-разработчик

### Что работает хорошо — использовать

**`expand()` при старте** — TMA открывается не на полный экран по умолчанию. Первая строка кода: `Telegram.WebApp.expand()`. Без этого приложение выглядит как половина экрана.

**`MainButton` как единственный CTA** — нижняя кнопка Telegram нативно встроена в интерфейс. Использовать для «Следующий вопрос», «Смотреть результат», «Перейти к плану». Не дублировать собственными кнопками внизу — будет двойной footer.

**`CloudStorage` для прогресса** — сохранение результатов квиза, плана развития, уровня, стрика. До 1024 пар ключ-значение, хранится на серверах Telegram, доступно с любого устройства пользователя. Это замена localStorage — надёжнее и не теряется при смене устройства.

**`HapticFeedback`** — тактильный отклик обязателен для подростков:
- `impactOccurred('light')` при каждом ответе на вопрос квиза
- `notificationOccurred('success')` при завершении квиза и получении результата
- `selectionChanged()` при переключении вкладок или фильтров

**`themeParams`** — Telegram передаёт цвета темы пользователя (тёмная/светлая). Обязательно читать и применять. Жёстко заданная тёмная тема без `themeParams` будет выглядеть неправильно у пользователей со светлой темой.

**`ClosingConfirmation`** — включать в начале квиза, выключать после показа результата. Если пользователь случайно нажмёт закрыть в середине квиза — Telegram спросит «точно закрыть?». Защищает от потери прогресса.

**`shareMessage()` и `shareToStory()`** — нативный шаринг результата. После получения архетипа — кнопка «Поделиться» вызывает нативный диалог Telegram. Никакого внешнего шаринга не нужно.

**`BackButton`** — нативная кнопка назад в хедере. Слушать событие `backButtonClicked` и реализовывать переход к предыдущему вопросу. Не делать собственную кнопку «Назад» — это дублирование и плохой UX.

**`viewportStableHeight`** — использовать для расчёта высоты layout, а не `viewportHeight`. Стабильная версия не прыгает при появлении клавиатуры. Критично для экранов с текстовым вводом.

### Что лучше не делать — ограничения

**Горизонтальные свайпы от края экрана на iOS** — конфликт с системным жестом закрытия TMA. Свайп-карточки для профессий делать вертикальными или через кнопки «Нравится / Не моё», не Tinder-свайп.

**Кастомные диалоги-overlay** — вместо собственных модальных окон использовать `showPopup()`, `showAlert()`, `showConfirm()`. Нативные диалоги Telegram выглядят правильно и работают надёжнее.

**Открывать внешние ссылки напрямую** — без `openLink()` TMA закроется. Все ссылки (на вузы, курсы, статьи) открывать через `Telegram.WebApp.openLink(url)`.

**Тяжёлый JS** — TMA грузится в WebView внутри Telegram. LCP должен быть ≤ 2.5 сек, INP ≤ 200 мс. Минимальный JS-бандл, lazy loading компонентов, skeleton screens вместо спиннеров.

**`safeAreaInset` игнорировать нельзя** — на iPhone с «чёлкой» и на Android с навигационной панелью контент обрезается. Добавлять отступы через `Telegram.WebApp.safeAreaInset` и `contentSafeAreaInset`.

**Drag-and-drop** — нет нативной поддержки, сложно реализовать надёжно в WebView. Для сортировки шагов плана — кнопки «вверх/вниз» или долгий tap с библиотекой.

### Архитектурные решения для ПрофНавигатора

| Задача | Решение | Почему |
|---|---|---|
| Хранение профиля | CloudStorage | Работает на всех устройствах, не теряется |
| Офлайн-кеш профессий | DeviceStorage (5 MB) | Быстрый доступ без запроса к серверу |
| AI-запросы | Edge Functions (Vercel) | Нет CORS, скрыт API-ключ, дешевле чем serverless |
| Оплата | Telegram Stars | Нативно, без внешних шлюзов, минимальное трение |
| Аналитика | Яндекс Метрика | Закон РФ 152-ФЗ запрещает Google Analytics |
| AI-модель | Gemini 2.5 Flash-Lite | $0.00045 за квиз; есть бесплатный tier |
| Авторизация | Telegram initData | Пользователь уже авторизован, не нужна регистрация |

## Итоговый список рекомендаций

### Критично — без этого продукт не работает

1. **Максимум 15 вопросов** — лучше 12. Один экран — один вопрос, карточки-ответы, автопереход
2. **Результат показывать бесплатно и сразу** — никаких форм перед результатом
3. **Архетип с именем + топ-3 профессии + один конкретный шаг** — не абстрактный текст
4. **Radar chart** — обязателен на экране результата, делает результат ценным визуально
5. **Анимация «считаем» 2–3 сек** — перед результатом, повышает воспринимаемое качество алгоритма
6. **`expand()` + `themeParams` + `ClosingConfirmation`** — три обязательных вызова в начале TMA
7. **CloudStorage** — сохранять прогресс, результаты, план; не полагаться на localStorage

### Важно — делать в первые 1–2 месяца

8. **Нелинейный прогресс-бар** — нарочито быстрый в начале, снижает dropout
9. **Кнопка шаринга результата** — через `shareToStory()` и `shareMessage()`; это бесплатный маркетинг
10. **Экран повторного визита** — персонализированное приветствие для вернувшегося пользователя
11. **Return-хуки через бота** — сообщения с новыми профессиями, напоминания о плане, стрик-уведомления
12. **Freemium-блокировка** — базовый результат бесплатно, детальный план/AI-чат размыт + кнопка «Разблокировать»
13. **HapticFeedback** — на каждый ответ и на завершение квиза
14. **Skeleton screens** — вместо спиннеров при загрузке любых данных

### Стратегически важно — закладывать с первого дня

15. **Не копировать чужой контент профессий** — у CareerExplorer 1500 карьер, это перегрузка. Наша сила — 30–50 профессий, но с российским контекстом, ЕГЭ и конкретными вузами
16. **Родительский режим** — отдельный view результатов ребёнка с рекомендациями «как поддержать». Это и retention, и B2B-крюк для школ
17. **Честность алгоритма** — объяснять почему конкретная профессия: «Ты ответил X → поэтому мы предлагаем Y». Никакого чёрного ящика
18. **Независимость** — не продвигать курсы в отчёте. Это главный минус ПроФориентатора, убивающий доверие
19. **Масштаб через школы** — первый B2B-пилот даёт данные, авторитет и дистрибуцию. Dashboard для учителей = конкурентный ров
