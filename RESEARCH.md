# RESEARCH.md — Копилка исследований

Сюда складываем все результаты исследований, анализов, данные из источников — в сыром виде.

**Процесс:**
1. Провели исследование → добавили сюда
2. Claude анализирует и распределяет выводы по рабочим файлам (STRATEGY.md, PERSONAS.md, COMPETITORS.md и др.)
3. Этот файл остаётся как первичный архив

---

## Формат записи

```
### [Дата] Название исследования / источника

**Что изучали:** ...
**Источник:** ...
**Находки:**
- ...
- ...

**Выводы распределены:** [да / нет / частично]
```
