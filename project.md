## Название проекта

**ПрофНавигатор** (`prof-navigator-platform`)

## Видение системы

ПрофНавигатор — это **не квиз и не база вузов**. Это персональная AI-система сопровождения человека — от выбора пути после 9 класса до карьерного роста на предприятии или в компании.

Квиз — это только входная точка, первые 5 минут. Дальше — долгосрочный AI-спутник, который знает твой профиль, помнит тебя, отвечает на вопросы которые появляются через год и через три, и растёт вместе с тобой.

**Важно:** доверие строится к системе ПрофНавигатор — не к личности автора. Личных консультаций нет.

### Миссия

> Помогать каждому человеку найти своё место — в профессии, в жизни и в мире. Не только выбрать профессию, но и стать тем, кто в ней состоится: профессионалом, личностью, частью сильной семьи и опорой для своей страны.

**Три уровня ценности:**
- **Профессия** — найти направление, выбрать путь, вырасти на работе
- **Личность** — развить навыки, которые делают человека сильным: целеполагание, критическое мышление, коммуникация, самодисциплина
- **Жизнь** — осознанность, здоровые отношения, крепкая семья. Человек, знающий своё место, строит жизнь, а не плывёт по течению

### Что умеет полная система

**Диагностика**
Мини-квиз → глубокий опрос → персональный AI-отчёт (не шаблон, а индивидуальный анализ).

**AI-помощник в приложении**
Отвечает на любые вопросы пользователя: о поступлении, профессиях, колледжах, вузах, предприятиях, навыках. Знает профиль конкретного человека, даёт персональные рекомендации — не общие советы.

**Индивидуальный маршрут на весь путь**
```
После 9 класса   → колледж или 10–11? куда конкретно? как поступить?
После 11 / колледжа → какой вуз? какие ЕГЭ? как готовиться?
Во время учёбы   → что развивать? где практика? какие навыки?
Начало карьеры   → как расти? какие компетенции прокачивать?
```

**База знаний**
Вузы, колледжи, предприятия, профессии — с конкретикой по региону, баллам, перспективам.

**Прокачка навыков и личностный рост**
Не только «кем быть», но и «как стать тем, кто достигнет своих целей»:
целеполагание, самодисциплина, критическое мышление, ТРИЗ, переговоры, решение задач — конкретные методы и практики.

### Платформа

| Канал | Роль |

**Монетизация:** подписка (доступ к полной системе и AI-помощнику).

### Чем это отличается от конкурентов

Конкуренты дают **одноразовый результат** — прошёл тест, получил список профессий, закрыл вкладку.
ПрофНавигатор — **долгосрочный спутник**: система помнит пользователя и сопровождает его годами.

## Что это (v1 — текущий этап)

ПрофНавигатор v1 — бесплатный онлайн-квиз профориентации для подростков 14–18 лет и их родителей. За 10 вопросов и 5–7 минут пользователь получает персональный профессиональный профиль и конкретный маршрут: какие профессии подходят, куда поступать, что развивать.

Цель v1 — проверить спрос через бесплатный инструмент, до того как строить полную систему.

## Целевая аудитория

### Полный охват (вся система)

| Сегмент | Возраст | Главный вопрос | Приоритет |
|---|---|---|---|
| **Школьник** | 14–17 | Кем быть? Куда после 9-го? Что сдавать? | 🔴 v1 |
| **Родители** | 35–55 | Как помочь ребёнку не ошибиться? | 🔴 v1 |
| **Студент** | 17–23 | Правильно ли выбрал? Что развивать? | 🟡 Фаза 2 |
| **Молодой специалист** | 22–35 | Как расти на предприятии? Правильное ли направление? | 🟡 Фаза 3 |
| **В середине пути** | 35–50 | Как сменить профессию без потери? Это точно моё? | 🟢 Фаза 4 |
| **Новая глава** | 50–65 | Чем заниматься дальше? Как применить опыт? | 🟢 Фаза 5 |

**Приоритет на v1:** подростки 14–17 лет + родители 8–11 класса.

### Почему расширяем аудиторию

Все конкуренты сфокусированы на школьниках — рынок переполнен снизу. Сегменты 25–65 лет практически без качественных инструментов — и там платёжеспособная аудитория с реальной болью.

## Какую проблему решает

**Проблема:** подростки и родители сталкиваются с одним из самых важных выборов в жизни — выбором профессии — без нормального инструмента. Существующие решения либо слишком длинные (60–157 вопросов), либо дорогие (6 900 руб.), либо без российского контекста (ЕГЭ, вузы), либо дают абстрактный результат без конкретного плана.

**Решение ПрофНавигатора:** быстрый (10 вопросов, 5–7 мин) + бесплатный + российский контекст (ЕГЭ, вузы РФ) + современный UX + конкретный маршрут действий.

---

## Уникальное торговое предложение

> Узнай свой профессиональный профиль за 5 минут — и получи конкретный план: какие профессии подходят, куда поступать, что развивать прямо сейчас.

Ни один конкурент не сочетает все четыре: **быстро + бесплатно + российский контекст + конкретный план**.

## Воронка

```
Реклама / органика / ролики
        ↓
Лендинг (описывает суть и ценность)
        ↓
Квиз (10 вопросов, 5–7 мин, бесплатно)
        ↓
Загрузочный экран (2–3 сек анимации)
        ↓
Страница результата (профиль + маршрут + CTA)
        ↓
Email-гейт / Telegram-бот (удержание)
        ↓
Консультация Павла / платный расширенный отчёт
```

## Функции на будущее

### Этап 2 — доверие и удержание

| Функция | Зачем |
|---|---|
| Email-захват перед результатом | Лид остаётся, даже если закрыл вкладку — конверсия ~40% |
| Автоматическое письмо с результатом | Конвертирует лида в клиента асинхронно |
| Страница «О Павле» | Доверие к эксперту — ключевое для родителей |
| Кейсы учеников с фото | Социальное доказательство убеждает лучше любой статистики |
| Блок отзывов на лендинге | Главный конвертор для «Мамы Ирины» |
| Уникальный URL для каждого результата | Делиться ссылкой + SEO-индексация |

### Этап 3 — монетизация и рост

| Функция | Зачем |
|---|---|
| Платный расширенный отчёт (490–790 руб.) | Первая прямая монетизация, конверсия 5–12% |
| PDF-скачивание результата | Воспринимаемая ценность; родителям есть что показать |
| Telegram-бот | Главный актив — подписчик важнее разовой продажи |
| Отдельный лендинг для родителей | Другой язык, другие боли, другой CTA |

### Этап 4 — масштаб

| Функция | Зачем |
|---|---|
| B2B — лицензии для школ (15–50 тыс. руб./год) | Масштаб без роста расходов на трафик |
| Подписная модель / личный кабинет | Регулярный доход, обновления маршрута |
| Продукт для взрослых 30–45 (переориентация) | Отдельный рынок |
| Блог / SEO-статьи | Бесплатный органический трафик |

## Технологии

### Сейчас (v1 — статика)

| Слой | Решение | Почему |
|---|---|---|
| **Страницы** | HTML + CSS + JS (один файл, без фреймворков) | Работает без интернета, нет зависимостей |
| **Хостинг** | GitHub Pages (бесплатно) | Уже настроен, достаточно для v1 |
| **AI-отчёт** | JS-шаблоны по профилю | Проверяем спрос до инвестиций в бэкенд |
| **Хранение данных** | localStorage | Без бэкенда и без аккаунтов |
| **Аналитика** | Яндекс Метрика | Единственный законный вариант в РФ (GA4 нарушает 152-ФЗ с июля 2025) |
| **Шаринг** | Clipboard API (копирует текст) | Без бэкенда |

### Этап 2 — после подтверждения спроса

| Слой | Решение | Почему |
|---|---|---|
| **Хостинг** | Vercel (100 ГБ бесплатно, Edge Functions) | Serverless для AI API без сервера |
| **AI API** | Gemini 2.5 Flash-Lite | Самый дешёвый: ~$0.00045/запрос, есть бесплатный тир |
| **Email** | SendPulse или Unisender | Российские серверы, рублёвая оплата, 15 000 писем/мес бесплатно |
| **Лиды (CRM)** | Airtable (free, 1 000 записей) | Без бэкенда, API из браузера |
| **Платежи** | ЮKassa (2.8–3.5%) | Работает с самозанятыми, рублёвые выплаты |

## Что может пойти не так (риски)

| Риск | Вероятность | Митигация |
|---|---|---|
| Подростки бросают квиз на 6–8 вопросе | Высокая | Короткие вопросы, прогресс-бар, авто-переход — держат темп |
| JS-шаблоны слишком общие, нет ценности | Средняя | Контролируем по отзывам; апгрейд на AI после 50+ прохождений |
| «500+ учеников» вызывает недоверие | Средняя | Заменить на реальные отзывы после первых 10 пользователей |
| 152-ФЗ и данные несовершеннолетних | Есть | Минимальное согласие в форме / футере до запуска трафика |
| Нет трафика без рекламного бюджета | Высокая | Контент-стратегия: короткие ролики VK/Rutube, Telegram-бот |
