# ПрофНавигатор — Документация проекта

## Что это за проект

**ПрофНавигатор** — AI-платформа профориентации, которая помогает подросткам и
родителям пройти путь от растерянности к ясному профессиональному выбору.

Платформа соединяет профориентацию, психологическую диагностику, анализ рынка труда
и персональные AI-рекомендации — чтобы человек получил не абстрактный список
профессий, а конкретный маршрут развития на 1–5 лет.

Проект создан и ведётся **Павлом Ежовым** — экспертом по профориентации школьников
с опытом 5+ лет и более 500 учеников.

## Для кого

### Основные сегменты аудитории

| Аудитория | Главный вопрос | Боли |
|---|---|---|
| **Родители учеников 8–9 класса** | «Куда после 9-го: колледж или 10–11 класс?» | Боятся ошибиться, не понимают рынок профессий, не знают как говорить с подростком |
| **Родители учеников 10–11 класса** | «Какой вуз, ОГЭ/ЕГЭ и профессию выбрать?» | Сроки поджимают, выбор ЕГЭ уже влияет на будущее, много денег на репетиторов |
| **Подростки 14–18 лет** | «Кем мне быть, если я сам не понимаю?» | Давление родителей, страх ошибиться, непонимание своих сильных сторон |
| **Молодые люди 18–25 лет** | «Я учусь/работаю, но не уверен, что это моё» | Разочарование в специальности, желание сменить направление |
| **Взрослые 30–45 лет** | «Чем мне заниматься дальше?» | Переориентация, переход в новую профессию *(отдельный продукт — в перспективе)* |

## Как работает воронка

```
Реклама / статья
       ↓
Лендинг (описывает суть и ценность)
       ↓
Бесплатный мини-квиз (5–7 минут)
       ↓
AI обрабатывает ответы → Отчёт-маршрут
       ↓
Предложение: AI-консультант или полный расширенный тест
       ↓
Подписка / платный углублённый продукт
```

**Ключевой принцип:** дать максимальную ценность бесплатно, чтобы пользователь
сам захотел остаться и получить больше.

## Стиль дизайна

**Общая концепция:** тёмный премиальный UI с живыми акцентами.

| Элемент | Решение |
|---|---|
| **Фон** | Тёмно-синий `#070e1b` / `#080e1a` с радиальными градиентными свечениями |
| **Акцентные цвета** | Янтарь `#f59e0b`, оранжевый `#f97316`, голубой `#0ea5e9`, зелёный `#10b981` |
| **Текст** | Белый `#f1f5f9`, приглушённый `#94a3b8` |
| **Карточки** | Glass morphism: `backdrop-filter: blur`, полупрозрачный фон, тонкая граница |
| **Кнопки** | Градиентные янтарь→оранжевый, пульсирующая анимация `box-shadow` |
| **Анимации** | Появление при скролле (IntersectionObserver), плавающие orb-свечения, мерцающие звёзды |
| **Иконки** | Только inline SVG — без внешних зависимостей |
| **Шрифт** | Системный стек: `-apple-system, BlinkMacSystemFont, 'Segoe UI', system-ui` |
| **Адаптивность** | Mobile-first, breakpoints 680px и 420px |
| **Технологии** | Чистый HTML + CSS + JS, никаких фреймворков и CDN |

**Символика:** компас — главный визуальный образ проекта. Компас даёт ориентир,
AI строит маршрут. Это единый метафорический стержень всего бренда.

## Сильные стороны проекта

1. **Не просто тест, а маршрут** — конкретный путь на 1–5 лет, а не список типов личности
2. **Учитывается рынок будущего** — востребованные профессии, реальные предприятия города
3. **Учитывается готовность подростка** — не только «кем хочешь быть», но и «насколько готов»
4. **Учитывается призвание** — где не просто интерес, а возможное предназначение
5. **Полезен и подростку, и родителю** — два угла зрения на одну задачу
