## Шаг 1 — HTML-каркас

**Что делаем:** три `<section>` внутри `<body>`, функция переключения экранов.

**Задачи:**
- Базовый `<!DOCTYPE html>` с `<meta charset>`, `<meta viewport>`, `<title>`
- `<section id="screen-landing" style="display:block">`
- `<section id="screen-quiz" style="display:none">`
- `<section id="screen-result" style="display:none">`
- Функция `showScreen(id)` в `<script>`:
  ```javascript
  function showScreen(id) {
    document.querySelectorAll('[id^="screen-"]').forEach(s => s.style.display = 'none');
    document.getElementById(id).style.display = 'block';
    window.scrollTo(0, 0);
  }
  ```
- Временные кнопки для переключения (для отладки, убрать в конце)

**Критерий готовности:** клик переключает между тремя экранами, скролл сбрасывается.

## Шаг 4 — Анимации лендинга

**Что делаем:** плавные появления при скролле, пульсирующие кнопки.

**Задачи:**
- Hero: `animation: fadeInUp` с задержками (H1 → 0ms, подзаголовок → 200ms, кнопка → 400ms)
- `IntersectionObserver` для всех секций: `opacity: 0 → 1`, `translateY(20px → 0)`, transition 0.6s
- Карточки болей: cascade fade-in, задержки 0/100/200/300/400/500ms
- CTA-кнопки: `animation: pulse 2s infinite`
- FAQ-аккордеон: клик → `max-height: 0 → 500px`, transition 0.3s ease

**Критерий готовности:** прокрутка лендинга — блоки плавно появляются, кнопки пульсируют.

## Шаг 7 — Loading Screen

**Что делаем:** 3-секундный экран загрузки с анимированным прогрессом.

**Задачи:**
```javascript
function showLoading() {
  showScreen('screen-loading');
  const lines = [
    'Анализируем твои ответы...',
    'Сравниваем с 15 профессиональными профилями...',
    'Определяем твои сильные стороны...',
    'Профиль готов! ✓'
  ];
  let i = 0;
  const interval = setInterval(() => {
    textEl.textContent = lines[i++];
    if (i >= lines.length) clearInterval(interval);
  }, 750);
  // CSS animation прогресс-бара: width 0% → 100% за 3000ms
  setTimeout(() => {
    showResult(calculateResult());
    showScreen('screen-result');
  }, 3000);
}
```

**Критерий готовности:** плавный прогресс-бар 3 секунды, 4 строки сменяются, потом — экран результата.

## Шаг 10 — Edge Cases

**Что делаем:** 3 граничных сценария из SPEC.md Section 9.

**Задачи:**

**Повторный визит (`pn_result` есть в localStorage):**
```javascript
// При клике CTA на лендинге → показать экран перед quiz
if (localStorage.getItem('pn_result')) {
  showRepeatVisitScreen(); // «Ты уже проходил → [Посмотреть] [Заново]»
} else { showScreen('screen-quiz'); }
```

**Прерванный квиз (`pn_quiz` есть, `pn_result` нет):**
```javascript
// При старте квиза → предложить продолжить
if (savedProgress && !savedResult) {
  showResumeScreen(); // «Вопрос 5 из 10 → [Продолжить] [Начать заново]»
}
```

**Ничья:**
```javascript
// В calculateResult()
const COMBINED = {
  'AT':'Аналитик-Творческий', 'TA':'Аналитик-Творческий',
  'AS':'Аналитик-Социальный', 'SA':'Аналитик-Социальный',
  // ... все 10 пар
};
if (top1.score - top2.score <= 1) {
  return COMBINED[top1.id + top2.id] || PROFILES[top1.id];
}
```

**Критерий готовности:** вручную заполнить localStorage и проверить каждый из 3 сценариев.

## Что не делать в vibe-кодинге (жёсткие запреты)

| Запрет | Почему |
|---|---|
| Любые `<link>` на внешние ресурсы | Файл должен работать offline |
| `import` или npm-зависимости | Только один HTML-файл |
| Email-форма ДО результата | Убивает конверсию |
| Кнопка «Далее» в квизе | Только автопереход |
| Скролл внутри экрана вопроса | Критично для мобиля |
