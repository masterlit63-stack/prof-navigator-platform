# Журнал ключевых решений — ПрофНавигатор

Здесь фиксируются решения, которые важно помнить и не пересматривать без причины.

---

## Решение #1 — Архитектура AI-отчёта (21 мая 2026)

**Решение:** Результат квиза формируется на JS-шаблонах без бэкенда и без реального AI на v1.

**Как работает:**
- Квиз собирает ответы пользователя в JS-объект
- Алгоритм на JS считает очки по 5 профилям (Аналитик, Творческий, Социальный, Технический, Предпринимательский)
- Топ-1 или топ-2 профиля определяют шаблон результата
- Шаблон выдаёт: профиль, профессии, рекомендацию (10–11 класс или колледж), первые шаги
- Всё работает на клиенте, без интернета, без бэкенда

**Почему не сразу настоящий AI:**
- Нужно сначала проверить, что пользователи вообще доходят до конца квиза
- Бэкенд (serverless + Claude API) добавляет сложность до того, как есть подтверждение спроса
- Шаблонный результат можно запустить за неделю — настоящий AI за 2–3 недели

**Когда пересматривать:**
Когда 50+ человек прошли квиз до конца и есть фидбек, что результат слишком общий.

**Следующий шаг после этого:**
Заменить JS-шаблоны на вызов Claude API через Vercel serverless function.

## Решение #2 — Хранение результата (21 мая 2026)

**Решение:** Результат квиза хранится в localStorage браузера.

**Как работает:**
- После прохождения квиза результат записывается в localStorage
- При повторном визите пользователь видит свой старый результат (с предложением пройти заново)
- Нет базы данных, нет аккаунтов, нет email на этом этапе

**Почему так:**
- Минимальная сложность для v1
- Не нужно собирать персональные данные (важно для несовершеннолетних и 152-ФЗ)
- Пользователь может «сбросить» результат очисткой кэша

**Ограничение:**
Результат привязан к устройству — нельзя открыть на другом телефоне. Принимаем это на v1.

## Решение #3 — Шаринг результата (21 мая 2026)

**Решение:** Кнопка «Поделиться» копирует готовый текст в буфер обмена.

**Как работает:**
- На странице результата — кнопка «Поделиться с родителями»
- По клику — генерируется текст вида: «Прошёл профориентационный квиз. Мой профиль: Аналитик. Подходящие профессии: UX-дизайнер, маркетолог. Пройди сам: [ссылка]»
- Пользователь вставляет текст куда хочет (Telegram, ВКонтакте, мессенджер)
- Нет Web Share API, работает везде

**Почему важно:**
Шаринг — главный канал вирусного роста без рекламного бюджета.
