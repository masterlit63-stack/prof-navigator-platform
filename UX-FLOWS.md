# Пользовательские пути — ПрофНавигатор

Создан перед разработкой quiz.html. Обновляется при изменении логики или структуры квиза.

---

## Основная воронка

```
Реклама / ролик / сарафан
        ↓
  landing.html
  (боли → как работает → пример отчёта → CTA)
        ↓
   quiz.html
  (10 вопросов → прогресс-бар → анимация результата)
        ↓
  result.html
  (профиль → профессии → маршрут → CTA на консультацию)
        ↓
  Telegram @bronzelit
  (консультация / платный расширенный отчёт)
```

## Детальный путь: quiz.html

### Структура экранов

```
Экран 0 — Вводный (старт)
  Заголовок: «Узнай свой профессиональный профиль»
  Подпись: «10 вопросов · 5–7 минут · Без регистрации»
  Кнопка: «Начать»

Экраны 1–10 — Вопросы
  Прогресс-бар сверху (например: «Вопрос 3 из 10»)
  Один вопрос на экране
  3–4 варианта ответа (карточки, не радиокнопки)
  По клику на вариант — автоматический переход к следующему
  Кнопка «Назад» есть, но не акцентируется

Экран 11 — Загрузка (анимация)
  «Анализируем твои ответы...»
  Прогресс-анимация 2–3 секунды (искусственная задержка для ощущения работы)
  Затем — редирект на result.html
```

### 10 вопросов квиза

**Блок A — Интересы и занятия (вопросы 1–3)**

**Q1.** Что тебе интереснее всего делать?
- Разбираться в сложных задачах и находить решения
- Создавать что-то руками или придумывать идеи
- Общаться с людьми и помогать им
- Строить, чинить, работать с техникой

**Q2.** Какой урок в школе тебе даётся легче всего?
- Математика, физика, информатика
- Русский, история, обществознание
- Биология, химия, психология
- Рисование, музыка, технология

**Q3.** Что ты делаешь в свободное время чаще всего?
- Смотрю видео о технологиях, играю в стратегии, программирую
- Рисую, пишу, снимаю, придумываю
- Общаюсь с друзьями, организую встречи, помогаю другим
- Собираю / разбираю что-то, занимаюсь спортом, мастерю

**Блок Б — Стиль работы (вопросы 4–6)**

**Q4.** Как тебе комфортнее работать?
- Один, сосредоточенно, в тишине
- В команде, где можно обсудить и придумать вместе
- С людьми — помогать, объяснять, поддерживать
- В движении, на объекте, руками

**Q5.** Что тебя больше мотивирует в работе?
- Решить сложную задачу лучше всех
- Создать что-то новое и красивое
- Видеть, что помог кому-то
- Получить конкретный осязаемый результат

**Q6.** Как ты обычно принимаешь решения?
- Анализирую данные, смотрю логику
- Доверяю интуиции и чувствам
- Советуюсь с другими, учитываю мнения
- Действую — потом разберусь

**Блок В — Ценности и будущее (вопросы 7–9)**

**Q7.** Что для тебя важнее в будущей профессии?
- Высокая зарплата и карьерный рост
- Свобода и творчество
- Польза людям и обществу
- Стабильность и понятный результат

**Q8.** Какая рабочая среда тебе ближе?
- Офис, компьютер, цифровой мир
- Студия, мастерская, пространство для творчества
- Работа с людьми — школа, больница, соцслужба
- Производство, стройка, лаборатория, улица

**Q9.** Что тебе сложнее всего?
- Говорить публично и убеждать людей
- Работать строго по инструкции без творчества
- Долго сидеть за компьютером в одиночестве
- Работать с абстракциями без конкретного результата

**Блок Г — Самооценка (вопрос 10)**

**Q10.** Как тебя чаще всего описывают другие?
- «Умный, логичный, всё объясняет»
- «Творческий, оригинальный, видит по-другому»
- «Добрый, понимающий, всегда поможет»
- «Надёжный, мастеровитый, всегда доделает»

---

### Логика подсчёта профилей

Каждый вариант ответа добавляет +1 к одному из 5 профилей:

| Вариант | Профиль |
|---|---|
| Аналитика / логика / данные | **Аналитик** |
| Творчество / идеи / красота | **Творческий** |
| Люди / помощь / общение | **Социальный** |
| Техника / руки / производство | **Технический** |
| (4-й вариант Q6 «действую сразу») | **Предпринимательский** |

После 10 вопросов — топ-2 профиля определяют шаблон результата.

## Детальный путь: result.html

### Структура страницы

```
Блок 1 — Профиль (hero)
  «Твой профиль: [Название]»
  Краткое описание профиля (2–3 предложения)
  Иконка / визуальный маркер

Блок 2 — Сильные стороны
  3 прогресс-бара с процентами (визуально как в примере отчёта на лендинге)
  Названия: например «Аналитика 84%», «Коммуникация 61%», «Творчество 73%»

Блок 3 — Подходящие профессии
  3–5 карточек профессий
  Каждая: название + 1 предложение почему подходит

Блок 4 — Рекомендация
  10–11 класс или колледж — с объяснением
  Направление: какой профиль/факультет искать

Блок 5 — Первые шаги
  3 конкретных действия которые можно сделать прямо сейчас

Блок 6 — CTA
  «Хочешь разобраться глубже?»
  Кнопка → Telegram @bronzelit
  «Поделиться с родителями» → копирует текст в буфер

Блок 7 — Повторное прохождение
  «Ответы не отражают тебя? Пройти заново»
```

### 5 шаблонов результата

**Аналитик**
- Профессии: Программист, Data Analyst, Финансист, Инженер, Системный архитектор
- Рекомендация: 10–11 класс → технический/математический профиль → IT или технические вузы
- Сильные стороны: Логика, Внимательность, Системность

**Творческий**
- Профессии: UX/UI дизайнер, Маркетолог, Копирайтер, Режиссёр, Архитектор
- Рекомендация: 10–11 класс → гуманитарный / творческий профиль → дизайн, журналистика, психология
- Сильные стороны: Креативность, Нестандартное мышление, Визуальность

**Социальный**
- Профессии: Психолог, Учитель, HR-менеджер, Врач, Социальный работник
- Рекомендация: 10–11 класс → гуманитарный профиль → психология, педагогика, медицина
- Сильные стороны: Эмпатия, Коммуникация, Умение слушать

**Технический**
- Профессии: Инженер-механик, Электрик, Строитель, Технолог производства, Пилот
- Рекомендация: Колледж → специальности технического профиля (быстрый вход в профессию)
- Сильные стороны: Практичность, Надёжность, Работа руками

**Предпринимательский**
- Профессии: Менеджер проектов, Предприниматель, Продюсер, Маркетолог, Трейдер
- Рекомендация: 10–11 класс → экономика/управление → бизнес-школы или стартап-акселераторы
- Сильные стороны: Инициативность, Скорость решений, Лидерство

## Пути выхода (где теряем пользователя)

| Точка | Причина потери | Что делаем |
|---|---|---|
| Лендинг → не нажал CTA | Не зацепило, не верит | Усилить заголовок, добавить отзывы |
| Квиз → бросил на вопросе 3–5 | Скучно, непонятно | Прогресс-бар, короткие вопросы, анимация |
| Квиз → закрыл вкладку | Отвлёкся | localStorage сохраняет прогресс — возвращается туда же |
| Результат → не перешёл в Telegram | Не убедил CTA | Усилить блок CTA, добавить конкретику оффера |

## Edge cases

**Родитель проходит квиз за ребёнка**
Вводный экран добавляет выбор: «Кто проходит квиз?» → «Я сам (подросток)» или «Я родитель, хочу понять своего ребёнка». Язык вопросов адаптируется.

**Повторный визит**
localStorage хранит результат → при заходе на quiz.html показывается экран: «Ты уже проходил квиз. Твой профиль: [Название]. Посмотреть результат или пройти заново?»

**Ничья в профилях**
Если два профиля набрали одинаково — показывается комбинированный профиль (например «Аналитик + Творческий» = UX-дизайнер, продуктовый менеджер).

**Мобильная клавиатура**
В квизе нет текстовых полей — только карточки с вариантами. Проблема виртуальной клавиатуры исключена.
