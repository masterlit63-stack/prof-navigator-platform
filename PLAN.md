## Этап 3 — Монетизация

> Цель: часть пользователей переходит на платный продукт

- [ ] **Расширенный отчёт (платный)** — полный отчёт с вузами, предметами ЕГЭ, 30-дневным планом
  - Ценообразование: базовый 490–790 руб., расширенный 990–1490 руб., с консультацией 2990 руб.
  - Подключить платёжку: Robokassa (для самозанятых) → после регистрации ИП: ЮKassa
- [ ] **Email-воронка** — серия из 7 писем после квиза; open rate 70%+ у писем с результатом
  - День 0: результат → день 1: «что это значит» → день 3: кейс → день 7: оффер → день 14: дожим
- [ ] **AI-консультант** — чат после получения отчёта, уточняющие вопросы
  - Первый шаг: JS-шаблоны (сейчас), апгрейд → Gemini 2.5 Flash-Lite (~$0.0005 на пользователя) после 50+ прохождений
- [ ] Страница подписки — что входит, сколько стоит, чем лучше бесплатного
- [ ] **Telegram-бот** — мини-диагностика → бесплатный PDF → предложение полного отчёта
  - Главный актив — подписчик важнее разовой продажи; платёж через ЮKassa Telegram Payments
