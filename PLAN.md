## Этап 2 — Доверие

> Цель: человек верит Павлу и продукту

- [ ] Страница «О Павле» — экспертность, подход, история, кейсы учеников
- [ ] Блок отзывов — реальные истории тех, кто нашёл свой путь (встроить в лендинг); заменить фиктивные «500+ учеников» реальной статистикой
  - **Отзыв как воронка в глубокий продукт** — один отзыв выстраивается по схеме:
    1. «Прошла мини-тест — понравились вопросы, получила результат»
    2. «Узнала, что есть большой опросник — удивилась, насколько конкретные результаты»
    3. «А потом оказалось, что есть целая система: отдельно для подростков, для родителей, для учителей»
    4. «Мне как маме стало проще помогать дочке — вижу её путь, понимаю как направлять»
    - Цель: читатель думает «хочу то же самое» → естественно переходит к большому опроснику и приложению
    - Это не реклама продукта — это история открытия. Встроить органично между другими отзывами.
- [ ] Кейсы учеников — 2–3 подробных истории «до и после» с фото

## Этап 2б — Глубокий опросник (100 вопросов)

> Цель: кто захотел больше после 10-вопросного квиза — уходит в глубину. Бесплатно.

- [ ] Большой опросник ~100 вопросов — детальная диагностика по всем 5 векторам + ценности + стиль жизни
  - Вход: кнопка в результате «Хочешь узнать себя глубже? → Полный опросник»
  - Охват: интересы, способности, ценности, стиль жизни, страхи, мотиваторы, отношения
- [ ] Персональная карта действий — не просто профиль, а конкретный маршрут со шагами на 30/90/180 дней
  - Привязана к реальным вузам, колледжам, курсам — не абстрактные рекомендации
  - Уровень глубины которого нет ни у одного конкурента в России
- [ ] **Симулятор пути** — интерактивный финальный блок после большого опросника
  - На развилке «Колледж» vs «10–11 класс → Вуз» подросток сам выбирает путь для «проживания»
  - Каждый путь раскрывается пошагово: специальности → учёба → практики → навыки → профессии → карьера → личностный рост → хобби
  - Персонализировано под профиль: только те специальности и профессии, которые подходят именно ему
  - «Секретные детали» пути — неожиданные плюсы, о которых мало кто говорит
  - Родительская версия: тот же механизм, но показывает путь ребёнка глазами родителя
  - Цель: не читать о будущем, а «прожить» его → снижает страх выбора, повышает вовлечённость
- [ ] Специальный формат результата для родителей — «Карта развития вашего ребёнка»
  - Вход: родитель уже прошёл мини-квиз (Этап 1) и убедился в полезности → переходит в большой тест
  - Результат большого теста для родителя: сильные стороны как родителя + зоны роста + конкретные советы
  - «Как разговаривать с вашим ребёнком», «Что поддержать», «Где отпустить»
- [ ] Специальный формат для учителей — «Профиль ученика» (для школьного пилота)

## Этап 3 — Монетизация

> Цель: часть пользователей переходит на платный продукт

- [ ] **Расширенный отчёт (платный)** — полный отчёт с вузами, предметами ЕГЭ, 30-дневным планом
  - Ценообразование: базовый 490–790 руб., расширенный 990–1490 руб., с консультацией 2990 руб.
  - Подключить платёжку: Robokassa (для самозанятых) → после регистрации ИП: ЮKassa
- [ ] **Email-воронка** — серия из 7 писем после квиза; open rate 70%+ у писем с результатом
  - День 0: результат → день 1: «что это значит» → день 3: кейс → день 7: оффер → день 14: дожим
- [ ] **AI-консультант** — чат после получения отчёта, уточняющие вопросы
  - Первый шаг: JS-шаблоны (сейчас), апгрейд → Gemini 2.5 Flash-Lite (~$0.0005 на пользователя) после 50+ прохождений
- [ ] Страница подписки — что входит, сколько стоит, чем лучше бесплатного
- [ ] **Telegram-бот** — мини-диагностика → бесплатный PDF → предложение полного отчёта
  - Главный актив — подписчик важнее разовой продажи; платёж через ЮKassa Telegram Payments

## Этап 3б — Карманный AI-помощник (приложение)

> Цель: пользователь получает персонального AI-друга в кармане — в Макс / Telegram

- [ ] **«Карманный помощник»** — персональный AI в Макс (VK Mini App) или Telegram-боте
  - Помнит всё о человеке: профиль, цели, историю разговоров
  - Ведёт, советует, рекомендует курсы и шаги персонально
  - Возвращается сам: еженедельные импульсы, новые вопросы, актуальная информация
  - Общается как умный друг, а не как FAQ-бот
- [ ] **Параллельная ветка для родителей** — тот же помощник, но с задачами родителя:
  - «Как понять своего ребёнка», «Как не навязать своё», «Что делать если конфликт по выбору профессии»
  - Знает профиль ребёнка (если ребёнок поделился) → родитель и ребёнок в одной системе
- [ ] Монетизация: базовый уровень бесплатно, продвинутые функции — подписка 290–490 руб./мес.
- [ ] B2B-версия для школ — «Профиль класса» для классных руководителей
