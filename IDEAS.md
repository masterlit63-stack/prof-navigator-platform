## Зоны роста в результате — ключевая идея доверия

> Разговор 25.05.2026. Суть: все говорят только о сильных сторонах — это убивает доверие.
> Честный результат = сильные стороны + зоны роста. Это и есть дифференциатор ПрофНавигатора.

**Почему это важно:**
- Пользователь видит только «ты крутой» → думает «это шаблон, это не про меня»
- Пользователь видит «вот где тебе сложно» → думает «да, это правда» → верит всему результату
- Родители ценят честность ещё больше подростков — они хотят объективный взгляд, не лесть

**Что добавить в результат (после блока «Сильные стороны»):**
- Блок «Над чем стоит поработать» (НЕ «Слабые стороны» — формулировка важна)
- 2–3 пункта: название зоны + 1 честное предложение + 1 микродействие «как начать»
- Прогресс-бары с низким % (25–45%) — визуальный контраст с высокими % сильных сторон
- Тон: без осуждения, с заботой, как умный друг — «это нормально, вот куда двигаться»

**Примеры зон роста по профилям (черновик):**
- Аналитик: сложно решать без достаточных данных / риск перфекционизма / эмоциональная коммуникация
- Творческий: незавершённые проекты / трудности со структурой и сроками / сложно в чужих рамках
- Социальный: ставить свои интересы выше чужих / жёсткие решения / риск эмоционального выгорания
- Технарь: самопрезентация и нетворкинг / трудно делегировать / нужна чёткая задача
- Предприниматель: доводить дела до конца / нетерпеливость / распыление на много проектов

**Это закладывает фундамент для:**
1. Персонализированной траектории роста (следующий этап продукта)
2. Платного углублённого разбора с Павлом — «Хочешь план по каждой зоне?»
3. Telegram-консультации — естественный следующий шаг после честного результата
4. Подписки на программу развития — человек видит что есть над чем работать

## Экосистема каналов привлечения

*Каждый канал выполняет свою роль — вместе они создают самоподдерживающуюся систему*

```
VK Clips / Rutube  →  даёт внимание (холодная аудитория)
Ozon / Litres      →  даёт доверие (люди ищут сами)
Telegram / бот     →  даёт подписчика (главный актив)
Диагностика/бот    →  даёт ценность (вовлечение)
Платный отчёт      →  даёт деньги
Подписка/консульт. →  даёт деньги долгосрочно
```

**Самая сильная формула:**
`Ролик (тревога/интерес) → PDF (польза) → Бот (диагностика) → Отчёт (платно)`

**Оптимальная стартовая последовательность:**
1. Квиз + отчёт на сайте (уже в работе)
2. Telegram-бот с мини-диагностикой и PDF
3. Ролики VK Clips / Rutube → трафик в бота
4. Litres: 5–7 PDF-книг по популярным темам
5. Ozon: физические карточки (этап 5)
